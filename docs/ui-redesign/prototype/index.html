落地红线

    

      
视觉改造不得触碰的 7 条

      

        1. .jf-body → .jf-sizer → .jf-window 三层契约，滚动只改 translateY 与窗口内容，sizer 高度不变

        2. 行高即坐标系：ROW_H = round(fontSize × 1.7)，改字号/密度必须 layout() 重算

        3. 事件委托：整棵树仅一个 click 挂在 body，靠 data-i 反查行下标

        4. 首屏之后补画的行加 jf-late，不播动画

        5. 压缩视图 COMPACT_MAX 只是屏幕策略；复制/下载走 outputText() 必须全文

        6. 左右两栏底栏恒为 34px，必须等高

        7. 跳行/搜索走 revealRow(index)，禁止 indexOf 全表扫描
