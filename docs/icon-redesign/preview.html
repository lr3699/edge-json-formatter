JSON Duo 图标 —— 分尺寸两档图形语言

黑色圆角底（#1C1C1F → #050506 的极浅渐变，纯黑不至于发死）。16px / 32px 用加粗单字母 J（墨迹高 74% 版面，笔画经描边加厚，有效笔画可达 2 物理像素以上）——四字母字标在 16px 下墨迹仅约 3 物理像素、单笔画不足 1px，任何字体都会糊成一条白线，故小尺寸换形。48px 起用完整字标「JSON」（字宽占版面 62%），左右以角括号「」夹住；角括号为矢量路径绘制，线宽固定 16/512，与字母笔画等重（CJK 全角字形会压小字号，故不直接用字形）；右括号横笔在底部（角朝右下），按 Microsoft YaHei / SimSun 真实字形校正。
