嵌套数组

键值对

一个「键 : 值」：空心胶囊是键、实心胶囊是值。黑白下也分得清，最直白。

多行键值

两行缩进的「键 : 值」，就是格式化之后的 JSON。元素最多、信息量最大。

字符串

一对引号夹一个实心胶囊，就是 value。引号是 JSON 里最抓眼的元素。

节点树
