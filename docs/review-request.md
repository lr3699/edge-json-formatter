# 评价引导文案（合规版，下次更新直接贴）

> 微软政策允许「请求评价」，不允许「用奖励换好评」或刷量。
> 下面这段接在商店描述末尾，语气不打扰、不承诺回报，符合要求。

## 中文（Store listings → Chinese 行 → Description 末尾）

```
■ 用着顺手的话

如果这个插件帮你省下过盯 JSON 的时间，欢迎在商店页留个评价和打分 ——
这是对小工具最实在的支持，也能让更多有同样需要的人找到它。
有任何问题或想要的功能，也可以直接在评价里提，我都会看。
```

## English（Store listings → English 行 → Description 末尾）

```
IF YOU LIKE IT

If this extension saves you time reading JSON, please consider leaving
a rating and review on the store page. It is the most practical way to
support a small tool, and it helps others with the same need find it.
Feedback and feature requests are welcome in the reviews - I read them all.
```
