核心功能

自动识别并美化

支持 application/json、application/*+json 等响应类型，打开即自动格式化；text/plain 返回的 JSON 也能自动识别。

可折叠的树形结构

任意节点单独折叠展开，也可一键全部折叠、全部展开，或直接「展开到第 N 层」。折叠节点会显示「… 13 个字段」摘要。

搜索定位

实时匹配所有键名与值（含被转义的内容），显示「3/11」命中计数，支持上下跳转，自动展开命中路径并高亮。

复制 JSONPath

点击任意键名即复制该字段的完整路径，例如 $.data.list[0].orderId；点击值则复制值本身。

保留 / 还原转义

默认保留源码写法，"a\nb" 就显示成 \n 两个字符；取消勾选则还原为真实的换行与中文。

数字精度零丢失

使用自研解析器而非 JSON.parse，600653836507516928 这类超出安全整数范围的订单号不会被改成 …930。

出错也能定位

JSON 格式非法时给出精确的行号列号并用插入符标出位置，还提供「宽松解析」一键处理注释、单引号、尾随逗号。

多种入口

打开 JSON 页面自动格式化、工具栏弹窗一键格式化、右键菜单格式化选中内容、快捷键 Alt+Shift+J。

安全与隐私

不采集任何数据

不上传内容、不做网络请求、无埋点统计、无远程代码。可在开发者工具 Network 面板自行验证。

与网页完全隔离

查看器运行在 Shadow DOM 中，既不会被网页样式影响，也不会污染网页；随时可点「还原原文」恢复默认显示。
